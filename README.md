# The Printer Finally Answers

[![make.fun](https://img.shields.io/badge/make.fun-bounty-7c3aed)](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907)

Entry for the make.fun bounty **[The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907)** (sponsor: Mang, $2 prize, free to enter).

## What it does

`main.py` (Python 3.13, standard library only, no network) writes a single
line of text — 1 to 240 characters — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set): the line the office printer
would finally say back to everyone staring at it. The paper jams, the
cryptic error codes, the thumps when it stops working — answered, in the
machine's own voice, with the comeback landing in a single read.

## Run

```sh
python3 main.py
```

Deterministic: two runs produce byte-identical output.
